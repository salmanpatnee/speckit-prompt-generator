```
5 Prompt Engineering Principles for AI-Powered Development 🎯

Not all prompts are created equal. The difference between a mediocre
AI output and a production-ready artifact often comes down to prompt
quality.

After months of experimentation with Claude and Speckit, I've
identified 5 core principles that dramatically improve results:

1️⃣ PARAGRAPH FORM
✓ Flowing prose instead of bullet lists
✓ Why: AI processes narrative better

2️⃣ INTENT-FIRST
✓ Outcomes & constraints before implementation
✓ Why: AI focuses on "why" not "how"

3️⃣ LOGICAL CHAINING
✓ Requirements build on each other
✓ Why: Clear cause-effect relationships

4️⃣ SUCCESS CRITERIA EMPHASIZED
✓ Repeat key standards for clarity
✓ Why: AI knows exactly what "done" looks like

5️⃣ NO IMPLEMENTATION DETAILS
✓ Architecture-level only, no tech specifics
✓ Why: AI captures intent without bias

These patterns can improve output quality by 3-5x.

The tool I just released (Speckit Prompt Generator) enforces all
5 automatically.

## GitHub README Hero Section Copy

# Speckit Prompt Generator

Transform your structured plans into high-quality Speckit-compatible
prompts—automatically.

## Why This Matters

Managing multi-phase projects with Spec-Driven Development is powerful.
But writing consistent, high-quality prompts for every phase is tedious
and error-prone.

**Speckit Prompt Generator solves this.**

Give it your plan document. Get back production-ready prompts that:
- Follow proven prompt engineering patterns
- Maintain consistent quality across phases
- Are ready to use with `/sp.specify` and `/sp.plan`
- Save you 2+ hours per project

## Quick Demo

**Input: Your plan document**
```markdown
## Phase 1 – Requirements Gathering
...

## Phase 2 – System Architecture
...
```

**Output: High-quality prompts**
```
Design the technical architecture for Phase 2: System Architecture.
Plan the overall system topology separating concerns with clear
service boundaries...
```

**Use with Speckit**
```
/sp.plan
[Paste Phase 2 prompt above]
```

→ Production-ready architectural plan generated.

## Key Features

✅ **Fully Automated** – Zero configuration, just run it
✅ **High Quality** – Enforces proven prompt patterns
✅ **Flexible** – Works with 1-20+ phase projects
✅ **Open Source** – MIT licensed, community-driven
✅ **Well Documented** – Complete guides and examples
✅ **Actively Maintained** – Regular updates and improvements

## Installation

```bash
# Copy to your skills directory
cp speckit-prompt-generator.skill ~/.claude/skills/

# Or clone from GitHub
git clone https://github.com/yourname/speckit-prompt-generator.git
```

[See detailed installation guide](./docs/installation.md)

## Getting Started

```bash
# 1. Create a plan document
cat > my-plan.md << 'EOF'
## Phase 1 – Requirements
...
EOF

# 2. Generate prompts
python scripts/generate_prompts.py my-plan.md

# 3. Use with Speckit
/sp.specify
# [Paste Phase 1 prompt]
```
