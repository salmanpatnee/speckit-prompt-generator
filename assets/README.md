# Assets Directory

This directory contains visual and media assets for the Speckit Prompt Generator project.

## Recommended Assets

### Hero Image
- **Size:** 1200x630px
- **Format:** PNG or JPG
- **Content:** Before/after comparison showing plan transformation

### Feature Icons
- **Size:** 64x64px or SVG
- **Icons needed:**
  - Automation (gear icon)
  - Quality (checkmark icon)
  - Speed (lightning icon)
  - Reusability (loop icon)
  - Documentation (book icon)

### Screenshots
- Example input (plan document)
- Example output (generated prompts)
- Usage demonstration

### Social Media Cards
- **Size:** 1200x630px
- **Variations:** Feature highlights, use cases, community

## Current Assets

- `example-output.md` - Sample generated output demonstration

## Contributing Assets

If you'd like to contribute visual assets, please ensure:
- High resolution and quality
- Consistent branding
- Appropriate licensing
- Pull request with asset and usage documentation
